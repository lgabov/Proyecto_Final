Pasos para que funcione el servidor.

1. Descargar la carpeta de node_modules desde el cmd yendose hasta la dirección donde se tenga la carpeta del proyecto, ya que estés en la carpeta
vas a escribir el comando "npm install" sin las comillas, eso te instalará todo lo necesario.
2. Descargar de igual forma el dotenv que es necesario para que funcione, se debe escribir en el cmd en la carpeta donde se tenga el proyecto el
comando "npm install dotenv" sin las comillas.
3. Para que funcione se debe descargar el archivo .env el cual tiene la contraseña, el puerto y todo lo necesario para que corra el servidor.
4. En el package.json se utilizó el nodemon y se especificó en el código que se use "npm start" para encender el servidor desde el cmd en la carpeta del proyecto.
5. Importante encender el xampp con el apache y el mysql para que el servidor pueda funcionar.
